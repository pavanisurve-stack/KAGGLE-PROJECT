# Netflix Movies and TV Shows Analysis

## Project Overview
This project focuses on analyzing Netflix Movies and TV Shows using Python. The aim is to explore the content available on Netflix and identify trends and patterns through data analysis and visualization.

## Objectives
- Analyze the distribution of Movies and TV Shows on Netflix.
- Explore content distribution across countries.
- Study the release-year trends of Netflix content.
- Analyze yearly trends in content added to Netflix.
- Identify the most common genres on the platform.

## Dataset
The project uses the Netflix Movies and TV Shows dataset (`netflix_titles.csv`), containing information about titles, directors, cast, countries, release years, ratings, durations, genres, and dates added to Netflix.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Contents
- `netflix_analysis.ipynb` – Jupyter Notebook containing the analysis, Python code, and visualizations.
- `netflix_titles.csv` – Dataset used for the analysis.

## Analysis Performed
1. Dataset Overview
2. Data Cleaning and Preprocessing
3. Content Distribution by Country
4. Movies vs TV Shows Distribution
5. Content Distribution by Release Year
6. Year-wise Trend of Content Added to Netflix
7. Top 10 Most Common Genres
8. Key Findings and Conclusion

## Conclusion
This project provides insights into Netflix's content library through exploratory data analysis and visualizations. It helps understand content distribution, release patterns, and genre trends.
